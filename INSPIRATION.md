The shot mix's filters (`crates/sound/src/shot/dsp.rs`) are Andrew Simper's linear trapezoidal state-variable filter from his Cytomic technical note "Solving the continuous SVF equation using trapezoidal integration and equivalent currents" (2013), and its smooth curves (`crates/sound/src/shot/curve.rs`) Fritsch and Carlson's monotone cubic interpolation (1980); formulas only, no code taken. Its road, spray, squeal, whoosh and city layers are built from pfx-sound's own noise, oscillators and those filters.

The spot cone's smooth falloff is glTF's `KHR_lights_punctual` (the angular attenuation the extension recommends, the one the tracer's `LightShape::Spot` already uses), and the range window is the one the live lights had.

The voice effects skip two sources on licence: Faust's `ve.vocoder` sits in the LGPL section of `vaeffects.lib`, and aubio's onsets are GPL; neither was used.

[pissang/oidn-web](https://github.com/pissang/oidn-web) (MIT), a WebGPU runtime for the same weights, was read for its channel-blocked layout; no code was taken from it.

The sim input journal (`crates/core/src/sim/journal.rs`) takes its varint and zigzag from [Protocol Buffers' wire encoding](https://protobuf.dev/programming-guides/encoding/), its change mask with per-field deltas from Quake 3's delta-compressed snapshots, and its seed-plus-inputs log from Doom's `.lmp` demos; formulas only, no code taken. The text generator (`crates/core/src/words.rs`) follows the slot-template grammar of [Tracery](https://github.com/galaxykate/tracery) (Apache-2.0); the idea only, no code taken. The PCM stream's ring (`crates/sound/src/pcm.rs`) follows [rtrb](https://github.com/mgeier/rtrb) (MIT OR Apache-2.0): a fixed buffer, a head and a tail in Acquire and Release order, positions counted to twice the length so a full ring differs from an empty one; the layout only, no code taken. Bevy's motion blur (`bevy_post_process` 0.20.0, `src/motion_blur`, MIT OR Apache-2.0) was read for where the pass runs (after TAA, before bloom and depth of field) and its shutter convention; it is a single gather without the tile passes, and no code was taken from it.

The `.cube` reader (`crates/post/src/cube.rs`) follows Adobe's Cube LUT Specification 1.0 and DaVinci Resolve's `LUT_1D_INPUT_RANGE` and `LUT_3D_INPUT_RANGE`; the format only, no code taken.

The wet-surface layer (`crates/materials/src/wet.rs`, `crates/materials/src/wgsl/wet.wgsl`) follows Sébastien Lagarde's published model, [Water drop 3b: physically based wet surfaces](https://seblagarde.wordpress.com/2013/04/14/water-drop-3b-physically-based-wet-surfaces/) (2013): the porosity remap from roughness (start 0.5, span 0.4), the darkest diffuse factor 0.2 with metals excluded, and the half-weighted gloss gain; and from [Water drop 2b: dynamic rain and its effects](https://seblagarde.wordpress.com/2013/01/03/water-drop-2b-dynamic-rain-and-its-effects/) the puddle that blends the shading normal flat by its water level (to the geometric normal, as 3b describes, where 2b uses straight up). Formulas and constants only, no code taken; the coat film, the puddle mask over the engine's own noise and its threshold curve are pfx's.
