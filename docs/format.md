# The scene format

The scene format is pfx-scene's (`crates/scene`), which owns it: its spec is [scene-format.md](scene-format.md), the crate is introduced in [scene-crate.md](scene-crate.md), and the `.pitofx` file a scene packs into is [pfx-file.md](pfx-file.md). What pfx does with a loaded scene is in [scenes.md](scenes.md).
